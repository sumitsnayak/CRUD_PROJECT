# Python File Manager

A beginner-friendly command-line file management application built with Python to understand **CRUD operations** and basic file handling.

## 📌 About the Project

This project allows users to manage local files directly through a command-line interface.

It was built as a guided learning project while learning Python, with a focus on understanding how Python can interact with the local file system.

## ✨ Features

* Create a new file
* Read the contents of a file
* Rename an existing file
* Append new content to a file
* Overwrite file content
* Delete a file
* Basic error handling

## 🛠️ Technologies Used

* **Python**
* **pathlib**
* **File Handling**
* **Exception Handling**

## 🔄 CRUD Operations

| Operation | Function                            |
| --------- | ----------------------------------- |
| Create    | Create a new file and add content   |
| Read      | Read and display file contents      |
| Update    | Rename, append, or overwrite a file |
| Delete    | Delete an existing file             |

## 📚 Concepts Learned

Through this project, I practiced:

* Python functions
* User input
* File handling using `open()`
* File modes such as `r`, `w`, and `a`
* Working with file paths using `pathlib`
* Exception handling using `try-except`
* Basic CRUD concepts

## ▶️ How to Run

Make sure Python is installed on your system.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-file-manager.git
```

Open the project folder and run:

```bash
python main.py
```

Follow the instructions displayed in the terminal.
